# Kesho brand exports

Original project mark: repository-root `icon.svg` (K, sun and steps/path). This is not the Shujaaz logo or third-party magazine artwork.

`kesho.svg` is the vector master copy; `app-icon.png` is its 1024px transparent PNG export for Unity Player Settings. The WebGL template contains matching SVG/ICO/PNG favicon exports. Raster export was generated with Inkscape; ICO sizes are 16, 32 and 48 pixels, browser touch icon 192 pixels. Keep all derivatives consistent when changing the mark. `ProjectSetup.Configure` assigns the Unity player icon; its build must run before testing installation.
